# 상세정보 메타 (Media.meta)

> **소스:** [src/lib/format.ts](../../src/lib/format.ts), [scripts/mac-sync/sync.py](../../scripts/mac-sync/sync.py), [src/components/MediaGallery.tsx](../../src/components/MediaGallery.tsx)

`Media.meta`는 사진 상세정보를 담은 **JSON 문자열** 컬럼. 라이트박스의 "ⓘ 상세정보" 패널에 표시된다.

## PhotoMeta 구조 ([format.ts](../../src/lib/format.ts))

```
{
  camera?:      string  // 카메라 모델 (예: "iPhone 15 Pro Max")
  make?:        string  // 제조사 (예: "Apple", "Canon")
  lens?:        string  // 렌즈 (예: "EF50mm f/1.4 USM")
  aperture?:    number  // 조리개 (f값)
  focalLength?: number  // 초점거리 mm
  iso?:         number
  shutter?:     number  // 셔터속도 (초)
  latitude?:    number
  longitude?:   number
  place?:       string  // 주소 문자열
}
```

값이 없는 필드는 생략(null 제거). `parsePhotoMeta(raw)`로 안전 파싱(형식 오류 시 null).

## 추출 경로

- **맥 동기화**: [sync.py](../../scripts/mac-sync/sync.py) `_build_meta()`가 osxphotos export DB(`.osxphotos_export.db`)의 `photoinfo` JSON(`exif_info`, `latitude/longitude`, `place.address_str`)에서 위 구조를 만들어 `meta` 필드로 전송. 서버 [/api/ingest](../../src/app/api/ingest/route.ts) `normalizeMeta()`가 검증 후 그대로 저장.
- **소급**: 기존 사진은 export DB로 일괄 백필됨(마이그레이션 `media_meta` 이후).
- **직접 업로드/iCloud**: 현재 meta 미수집(EXIF 일부만 takenAt로 활용).

## 표시 ([MediaGallery.tsx](../../src/components/MediaGallery.tsx))

라이트박스 정보 패널에 촬영일시·종류·해상도와 함께 카메라·렌즈·촬영설정(`f/2.8 · 50mm · ISO 1600 · 1/200s`)·위치를 행으로 표시. GPS가 있으면 위치는 지도 링크. 셔터는 1초 미만이면 `1/N s`로 변환.
