# 데이터 모델 (Prisma 스키마)

> **소스:** [prisma/schema.prisma](../../prisma/schema.prisma)

SQLite + Prisma 7. cuid 기본 PK. 주요 모델과 필드:

## User
가족 구성원. `id`, `email`(unique), `name`, `passwordHash`, `role`(`"member"`|`"admin"`, 기본 member), `avatarUrl?`, `createdAt`. 관계: posts, comments, reactions, invitesSent, inviteUsed.

## Invite
초대코드. `code`(unique), `createdById`/`createdBy`, `usedById?`/`usedBy?`(unique), `expiresAt?`, `createdAt`. 가입 시 1회 소비.

## Child
아기 프로필. `name`, `birthDate`, `avatarUrl?`, `createdAt`. 관계: `media MediaChild[]`. 생일로 나이 라벨 계산.

## Post
사진 묶음 글. `authorId`/`author`(onDelete Cascade), `caption?`, `takenAt`(기본 now — 촬영일), `source`(`"upload"`|`"icloud"`|`"osxphotos"`, 기본 upload), `syncKey?`(unique, 동기화 묶음 키 `<출처>:<yyyy-mm-dd>`), `createdAt`. 관계: media, comments, reactions. 인덱스: `takenAt`.

## Media
개별 사진/동영상. 필드:
- `postId`/`post`(onDelete Cascade)
- `type`(`"image"`|`"video"`, 기본 image)
- `path` — 표시용 원본 상대경로(uploads 기준)
- `thumbPath?` — 썸네일 상대경로
- `width?`, `height?`
- `order`(기본 0) — 게시물 내 정렬 보조
- `takenAt?` — 개별 촬영시각
- `externalId?`(unique) — 외부 시스템 ID(사진 UUID/photoGuid). 중복 임포트 방지
- `meta?`(String) — 상세정보 JSON(카메라·렌즈·촬영설정·위치). [상세정보 메타 참조](상세정보_메타.md)
- `createdAt`
- 관계: `children MediaChild[]`. 인덱스: `postId`.

## MediaChild
사진↔아이 다대다 연결(osxphotos 인물 인식 기반, 아이별 필터용). `mediaId`/`media`(Cascade), `childId`/`child`(Cascade). 복합 PK `[mediaId, childId]`, 인덱스 `childId`.

## Comment
`postId`/`post`(Cascade), `authorId`/`author`(Cascade), `body`, `createdAt`. 인덱스 `postId`.

## Reaction
이모지 반응. `postId`, `userId`, `emoji`, `createdAt`. 유니크 `[postId, userId, emoji]`(사용자당 이모지 1개), 인덱스 `postId`. 이모지 집합은 [constants.ts](../../src/lib/constants.ts) `REACTION_EMOJIS`.

## AlbumSource
iCloud 공유앨범 연동. `token`(unique, 공개링크 토큰), `name?`, `lastSyncAt?`, `createdAt`.

## IngestToken
맥 에이전트 인증. `token`(unique), `name`(예: "아빠 맥북"), `lastUsedAt?`, `createdAt`. 값은 발급 응답에서만 노출.

## 마이그레이션 이력
`init` → `icloud_sync` → `osxphotos_ingest` → `media_child` → `media_meta`. ([prisma/migrations](../../prisma/migrations))
