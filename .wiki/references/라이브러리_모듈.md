# 라이브러리 모듈 (src/lib)

> **소스:** [src/lib](../../src/lib)

## media.ts — 미디어 파이프라인
세 입력 경로가 공유하는 핵심. `processBuffer(buf, {isVideo, ext})`:
- 동영상: 원본 그대로 저장(썸네일 없음).
- 이미지: EXIF 촬영일 추출(exifr) → sharp로 표시용 JPEG(최대 2400px, q88) + webp 썸네일(800px) 생성, EXIF 방향 적용.
- **HEIC 폴백**: sharp가 libheif 제한으로 실패하면 맥 `sips`로 JPEG 변환 후 재시도([HEIC sips 폴백](../decisions/003_heic_sips_폴백.md)).
- 그래도 실패하면 원본 저장(썸네일 null).
`processUpload(file)`는 웹 업로드 File을, `deleteMediaFiles()`는 삭제 시 파일 정리.

## storage.ts — 파일 경로
`uploadDir()`(`UPLOAD_DIR` 환경변수), `ensureUploadDir(sub)`, `resolveUpload(rel)`(디렉터리 탈출 방지 안전결합), `dateShard(d)`(`YYYY/MM`).

## auth.ts — 세션 헬퍼 (서버)
`setSession`/`clearSession`/`getSessionPayload`/`getCurrentUser`. 쿠키 httpOnly·sameSite lax·prod에서 secure.

## session.ts — 순수 토큰 (Edge 호환)
JWT 서명/검증(jose, HS256). `SESSION_COOKIE="session"`, 만료 30일. `SESSION_SECRET` 필수. **prisma·next/headers 의존 없음** → 미들웨어(Edge)에서 사용.

## sync.ts — iCloud 동기화 엔진
`syncICloud()`: 공유앨범 stream을 받아 미수집(`externalId`) 사진만 다운로드 → 미디어 파이프라인 → 촬영일별 Post 묶음. 동시 실행 잠금(`syncing`).

## icloud.ts — webstream 클라이언트
공유앨범 공개링크 토큰으로 사진 목록·다운로드 URL을 받는 비공식 API 클라이언트. `tokenFromUrl`, `fetchStream`, `fetchAssetUrls`, `bestDerivative`. 응답 형식 변동에 방어적.

## age.ts — 나이 라벨
`ageLabel(birth, on)` — 한국식 "생후 N일/N개월/N살". 상세는 [도메인 모델](../overviews/도메인_모델.md).

## format.ts — 표시 포맷
`mediaUrl(rel)`(보호 서빙 URL), `formatDate`/`formatDateTime`(KST), `timeAgo`, `PhotoMeta` 타입 + `parsePhotoMeta`. [상세정보 메타](상세정보_메타.md).

## posts.ts — 게시물 헬퍼
`reactionSummary`(이모지별 개수+내가 누른 것), `postInclude`(피드/상세 공통 Prisma include).

## constants.ts — 상수
`ROLES`, `MEDIA`, `REACTION_EMOJIS`, 허용 타입, `MAX_FILE_BYTES`(50MB 웹), `INGEST_MAX_FILE_BYTES`(300MB 에이전트).

## mime.ts — 확장자/타입 매핑
`extFromType`, `contentTypeForPath`.

## prisma.ts / password.ts
Prisma 클라이언트 싱글턴(better-sqlite3 어댑터) / 비밀번호 해시.
