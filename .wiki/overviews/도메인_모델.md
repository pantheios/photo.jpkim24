# 도메인 모델

> **소스:** [prisma/schema.prisma](../../prisma/schema.prisma), [src/lib/posts.ts](../../src/lib/posts.ts), [src/lib/age.ts](../../src/lib/age.ts)

## 핵심 개념

- **User** — 가족 구성원. `role`은 `admin` | `member`. 첫 가입자가 관리자.
- **Invite** — 관리자가 발급하는 1회용 초대코드. 가입 시 소비.
- **Post(게시물)** — "사진 묶음 글". 한 글에 여러 장(Media). 동기화 사진은 **촬영일(KST)이 같으면 한 Post에 묶인다**.
- **Media(미디어)** — 개별 사진/동영상 1개. 표시용 경로·썸네일·해상도·촬영시각·상세정보(meta)·외부ID 보유.
- **Child(아이)** — 아기 프로필(이름·생일). 생일로 "생후 N일" 라벨 계산.
- **MediaChild** — 사진↔아이 다대다 연결. osxphotos 인물 인식 결과로 태깅, 아이별 필터의 근거.
- **Comment / Reaction** — 게시물 댓글, 이모지 반응(사용자당 이모지 1개).
- **AlbumSource / IngestToken** — iCloud 공유앨범 연동 / 맥 에이전트 인증 토큰.

## 관계 요약

```
User ─< Post ─< Media ─< MediaChild >─ Child
 │        ├─< Comment
 │        └─< Reaction >─ User
 └─< Invite (createdBy / usedBy)
```

## 게시물 묶음 규칙 (동기화)

동기화로 들어온 사진은 `syncKey = "<출처>:<YYYY-MM-DD(KST)>"`로 같은 날끼리 한 Post에 합쳐진다 (osxphotos는 `osx:`, iCloud는 `<sourceId>:`). 직접 웹 업로드는 한 번의 업로드가 한 Post.

- Post의 `takenAt`은 그날 **가장 이른 사진 시각**으로 유지된다.
- 같은 사진의 중복 임포트는 `Media.externalId`(사진 UUID/photoGuid) 유니크로 차단.
- 이 그룹핑 사유는 [촬영일별 게시물 그룹핑](../decisions/004_촬영일별_게시물_그룹핑.md) 참고.

## 정렬

- 피드: Post를 `takenAt` **역순**(최신 날짜 먼저), 페이지당 15개.
- 게시물 안 사진: `takenAt` **오름차순**(촬영시각순, 없으면 뒤로 → `order` 보조). 공통 include는 [posts.ts](../../src/lib/posts.ts) `postInclude`.

## 나이 라벨 ([age.ts](../../src/lib/age.ts))

태어난 날을 "생후 1일"로 센다(한국식). 100일까지 "생후 N일", 12개월 미만 "N개월", 이후 "N살" 또는 "N살 M개월". 기준일은 사진의 촬영일이라, 옛 사진엔 그때의 나이가 표시된다.
